FAQ

Bagaimana cara pembayarannya?

Pembayaran diproses melalui Duitku Payment Gateway. Tersedia transfer bank, virtual account, e-wallet (OVO, ShopeePay, DANA), dan QRIS.

Apakah source code bisa di-custom?

Bisa. Hubungi WhatsApp untuk diskusi kebutuhan custom. Biaya tambahan tergantung kompleksitas.

Berapa lama proses pengerjaan jasa?

Konfigurasi jaringan 1-2 jam (remote). Deploy VPS 2-4 jam. Waktu bisa lebih lama jika ada kendala teknis.

Apakah ada garansi?

Source code garansi 7 hari untuk bug fixing. Jasa garansi 3 hari untuk troubleshooting.
